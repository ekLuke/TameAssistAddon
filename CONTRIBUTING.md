# Contributing

This is a GPL-3.0-only project. Submit original code or contributions compatible with that license. Do not commit proprietary Valheim/Unity/BepInEx binary assemblies.

Please open a GitHub issue for changes touching ZDO persistence, container inventory serialization, ownership, or crossplay, and describe how you tested with a dedicated server.

Do not claim that a feature is PS5-compatible until it has passed a vanilla PS5 client integration test.
